# WebHub
Project Name: WebHub

Welcome to WebHub, an e-learning platform designed for tech enthusiasts and learners. This website is a static, responsive platform built using HTML5, CSS, and JavaScript. It provides users with a comprehensive selection of educational resources, including curated books and video lectures on topics like programming, artificial intelligence, and software development.

Key features include:

Structured HTML content: Organized into categories and subcategories for easy navigation.
CSS styling and layout: Consistent and modern design across all pages.
Responsive design: Adaptable for different screen sizes (mobile, tablet, desktop).
Interactive forms: User registration form with validation and feedback.
This project is developed as part of a web development course to demonstrate knowledge of front-end technologies and responsive design.
